# TimeDate

This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework.

🎯 Usage
Commandes :

il est quel heure,
donne moi l'heure,
donne moi la date,
nous somme quel jour.

# Multi-room
The TimeDate plugin is fully multi-room.

# Multi-language
The TimeDate plugin relies solely on the system's available languages.
